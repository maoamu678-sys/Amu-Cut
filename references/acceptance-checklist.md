# 口播视频验收清单

## 文件身份

- [ ] 项目编号、源视频、工程、MP4、SRT 属于同一项目
- [ ] MP4 与 SRT 同名
- [ ] SRT 时间码完整、递增、无明显重叠或倒序
- [ ] 导出文件可以打开，时长不是 0 秒

## 内容

- [ ] 开头尽快进入主题
- [ ] 重复口播、失败重录、明显卡顿已处理
- [ ] 删除后语义仍然完整，不能只追求更短
- [ ] 结尾保留完整观点或行动建议

## 画面

- [ ] 人脸、嘴部和手势没有被字幕或字卡遮挡
- [ ] 画面没有突然跳黑、错位、错误缩放或明显闪烁
- [ ] B-roll 与说话内容有关，而不是为了填空
- [ ] 本条视频优先使用了新的语义 B-roll，并完成已用画面排除记录
- [ ] 全屏 B-roll 通常控制在 1–3 秒，切入和退出不打断语义
- [ ] 陌生人脸已避开、模糊或不影响观看

## 字幕与声音

- [ ] 字幕可读，安全边距足够，单行不挤成一团
- [ ] 字幕没有串项目、串人物或串语言
- [ ] 人声清楚，切点处没有爆音、断裂或突兀噪声
- [ ] 没有未经请求的背景音乐
- [ ] 音效只服务于语义、节奏或转折，没有盖住人声
- [ ] 已批准音效的峰值约以 -2.3 dBTP 为控制参考，并完成完整速度试听

## 状态

- [ ] 已通过自动检查
- [ ] 已生成可观看预览
- [ ] 用户已明确接受最终版本
- [ ] 如有发送，发送结果与接收确认分别记录
