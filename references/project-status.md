
# 项目交付状态模板

复制下面的表格，为每个编号项目单独维护一份：

| 项目 | 状态 | 证据 | 下一步 |
|---|---|---|---|
| 项目编号 | 待处理 / 剪辑中 / 待检查预览 / 已通过自动检查 / 待人工确认 / 已确认 / 已发送 / 已发布 | 文件路径、预览或用户确认原文 | 明确的下一步 |

## 状态含义

- **待检查预览**：已经有预览，但还没有用户确认。
- **已通过自动检查**：文件、时间码、音画和基础规则检查通过，不代表用户喜欢。
- **待人工确认**：需要用户看完整速度预览，尤其是跳切、字幕、B-roll 和人声。
- **已确认**：用户明确说可以使用或发布。
- **已发送**：已经完成发送动作，但不代表对方已收到。
- **已发布**：平台明确显示发布成功；上传、审核中、定时发布都不能写成已发布。
